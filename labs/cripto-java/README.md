# cripto-java

Laboratório do ebook: hash, HMAC, AES-GCM e assinatura RSA com o JDK.

```bash
cd labs/cripto-java
java Cripto.java
```

Requisitos: JDK 17+ e/ou `openssl`/`bash`. Os certificados e chaves gerados ficam em `certs/` (ignorado pelo Git). Material didático, não use em produção.

Documentação: [Sumário do ebook](../../README.md)
